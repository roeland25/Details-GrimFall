# Details
Modified version of the Details addon for GrimFall server. Doesn't use the ugly version of details that's on other websites like felbite, but uses the pretty, sleek, modern UI.

![Details meter](https://i.imgur.com/sZdoFgg.png)

#How to install
You install this addon like any other addon. You place it in your Grimfall\Games\Wotlk\Interface\AddOns\ folder. 
Make sure to rename the folder to "Details", if the Github download renames it something else.
